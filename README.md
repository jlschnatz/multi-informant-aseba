# Template - Correlative and Descriptive Studies - MSc

Use this template if you would like to initiate a folder with the standard subfolders (i.e., preregistration, materials, scripts, data, manuscript). This template includes three different preregistration files to choose from: the standard OSF preregistration file and the PRP-QUANT preregistration file, both for an elaborative preregistration, and the AsPredicted preregistration file.

## Project structure

- 1_Preregistration
- 2_Materials
- 3_Scripts
- 4_Data
- 5_Manuscript
- README.md

In **1_Preregistration**, you will find three word files.
1. *AsPredicted_preregistration.md*: This preregistration file covers eleven questions as used on [AsPredicted.org](https://aspredicted.org/) to capture the main parts of your study. 
2. *OSFpreregistration.md*: This preregistration file covers the questions of a preregistration performed on the OSF (as listed [here](https://help.osf.io/article/229-select-a-registration-template)) using the general preregistration format that leads to an extensive preregistration.
3. *PRP-QUANT-preregistration.md*: This preregistration file was specifically design for studies of psychology and created in a joint collaboration of the APA, BPS, COS, DGPs, and ZPID (more info [here](https://www.psycharchives.org/en/item/088c79cb-237c-4545-a9e2-3616d6cc8453)). This is the most elaborative preregistration to date and fits every kind of study in the field of psychology.

Decide on one of the files and edit this template by choosing *Edit single file* or *Open in Web IDE* through the *Edit* button. See "Additional resources" for more information on Markdown. The time of you last changes will be taken as the timestamp. Then delete the .md files you don't need anymore.

In **2_Materials** you can upload all the materials that you have used to conduct your study. These could be, for example, questionnaired used, survey files, or experimental scripts. If you do not have such materials or are not allowed to share your materials, delete this folder. If you are unsure, consult with your supervisor.

When you are done with the analyses of your dataset, you can upload the scripts (e.g., R scripts or JASP files) into the folder **3_Scripts**. 

The same applies for the dataset, which can then be uploaded to **4_Data**.

When you are ready with your manuscript (e.g., Master thesis, Forschungsmodul report, etc.), you can upload a final PDF version to **5_Manuscript**.

Last but not least, the **README.md** file is a Markdown text file that contains information about your project, including its purpose, contents, usage, and other details. It is usually located in the root directory. The README file serves as a quick reference for anyone trying to understand or use your project, and is an important resource for anyone who comes across it.
